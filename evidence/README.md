# Evidence policy

本目录只保存经过筛选的、可公开说明的结构化证据。当前索引：

- `round4_bootstrap_audit_evidence_20261024.json`：A1 loader、CP UART/GPIO/SPI 命令表、输入文件哈希、A7M4 参考边界和未决项。
- `SHA256SUMS.txt`：本公开文档集合的 SHA-256 清单，不包含原始固件。

证据中的地址是模块相对虚拟地址或文件偏移，不能直接当作相机物理地址。证据不代表运行时观察，也不代表外部接口已经可达。

公开仓库不应放入以下内容：

- 完整固件镜像、`BODYDATA.DAT`、`loader_nor.bin`、`cpapp-b.bin` 等原始二进制；
- 解密密钥、私钥、CodeMeter 许可材料或设备唯一数据；
- 可执行刷写工具、异常测试包、USB 发包器或补丁文件；
- 未经授权的运行时内存转储或用户机身数据。

若未来新增证据，应同时记录来源文件哈希、分析日期、地址语义和覆盖限制，并在报告中区分“静态事实”“推断”和“未知”。
